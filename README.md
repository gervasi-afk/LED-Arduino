# LED-Arduino
Foi desenvolvido um circuito utilizando Arduino, um botão e um LED no Tinkercad. O botão funciona como entrada, enquanto o LED funciona como saída. Quando o botão é pressionado, o LED acende; quando ele é solto, o LED apaga. A atividade demonstra como a programação e os componentes eletrônicos podem trabalhar juntos para controlar dispositivos.
